CASE STUDY 03 / AI / COMPUTER VISION

입술의 움직임에서
한국어 단어까지.

한국어 Lip Reading 딥러닝 기반 입술 읽기 시스템

청각 접근성과 소음 환경에서의 의사소통 가능성을 탐색한 전자공학종합설계 프로젝트입니다. 음성 없이 입술 움직임을 입력받아 제한된 단어를 출력하는 실험 시스템을 만들었습니다.

개발 기간
2024.03—07
팀 구성·역할
2인 팀 · 팀장 / 공동 수행
핵심 기술
MobileNetV2 · LSTM / dlib / SequenceMatcher
IN THIS PROJECT01 시스템 흐름02 내가 맡은 일03 문제 해결04 결과와 한계05 프로젝트 자료

01 / SYSTEM

입력에서 동작까지

  1. 01입술 영역 추출dlib · 10프레임 · 224×224 RGB
  2. 02영상 특징 추출MobileNetV2 · 1,280차원
  3. 03시간 정보·분류LSTM hidden 256 · 12음절
  4. 04단어 후보 매핑difflib.SequenceMatcher

사전에 정의한 음절 시퀀스와 예측 시퀀스의 유사도를 비교해 단어를 선택합니다. 문장 생성은 후속 목표이며 구현 범위에 포함되지 않습니다.

02 / CONTRIBUTION

팀원과 함께 맡은 일

01

직접 수집한 데이터

팀원과 함께 자원 참여자의 음절 발화 영상을 수집했습니다. 촬영 예산이 없는 상황에서 느리고 명확한 발화를 요청했고, 입술 검출에 실패한 영상은 다시 촬영했습니다.

02

영상과 시퀀스 모델 결합

dlib으로 입술을 잘라 10개 프레임을 입력으로 사용했습니다. MobileNetV2 특징을 LSTM으로 처리하고 12개 음절 클래스를 분류하는 구조를 공동으로 구현했습니다.

03

제한된 단어 출력으로 연결

분류한 음절을 모아 SequenceMatcher로 미리 정의한 단어 후보와 비교했습니다. 데이터 증강을 시도하고, 데이터를 5개 부분으로 나누는 교차 검증(5-fold)을 평가 절차에 포함했습니다. 모델·후처리를 함께 점검했습니다.

03 / TROUBLESHOOTING

관찰하고, 조정한 과정

데이터 수집과 촬영 조건의 편차

카메라와 조명 조건을 통일하지 않은 촬영 데이터에서 입술 검출 실패가 발생했습니다. 실패 영상을 재촬영하고, 느리고 명확한 발화를 요청해 입력 확보 과정을 개선했습니다.

음절 오분류가 단어로 전파되는 문제

예측 음절이 정답 시퀀스와 완전히 일치하지 않아도 유사도가 높은 후보를 고르도록 후처리를 구성했습니다. 단, 후보 밖의 자유로운 어휘를 인식하는 방식은 아닙니다.

04 / OUTCOME & REFLECTION

확인한 결과와 남은 과제

팀 결과

학습 영상에 참여하지 않은 본인과 팀원, 총 2명이 실시간 단어 출력을 시험했습니다. 수동으로 캡처를 시작한 뒤 입술 영상에서 음절을 예측하고 정해진 단어를 출력하는 흐름을 확인했습니다.

수치는 시스템 구성·평가 절차·시험 범위를 나타내며, 정확도나 성공률을 의미하지 않습니다.

구현 범위와 한계

두 사람의 시험을 광범위한 화자 독립성 검증으로 해석할 수 없습니다. 연속 발화를 자동 감지하거나 문장을 구성하지 않으며 실제 보조공학 제품으로 배포하지 않았습니다. 촬영 조건과 데이터 구성에 따른 일반화는 추가 검증이 필요합니다.

이 경험에서 배운 점

모델 구조뿐 아니라 데이터 수집 조건과 출력 규칙이 결과를 크게 좌우한다는 점을 경험했습니다. 한정된 후보에서의 단어 출력과 자유 발화 인식 사이의 차이를 구분하게 되었습니다.
