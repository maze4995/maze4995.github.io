# 김기현 | 로봇 소프트웨어·AI 포트폴리오

정적 HTML, CSS, JavaScript로 구성한 개인 포트폴리오입니다.

- 사이트: https://maze4995.github.io/
- 배포: GitHub Pages, `main` 브랜치의 루트(`/`)
- 로컬 확인: `python -m http.server 8765` 실행 후 http://localhost:8765 열기

`index.html`과 세 프로젝트 상세 페이지, 스타일 및 이미지 파일을 포함합니다. 별도 빌드나 서버가 필요하지 않습니다. `.nojekyll`은 정적 파일을 그대로 제공하도록 합니다.

외부 프로젝트 자료 링크는 각 원본의 접근 권한을 따릅니다.
